# スイッチフォルダーとタイムライン（簡易アニメーション）

PSD は絵の素材（レイヤーの画素）のまま、ほかのアプリでも開ける状態に保つ。
動きの情報は PSD の隣のサイドカーに持たせる。

## 進め方

1. 土台: PSD のレイヤー ID の保存と、サイドカーの読み書き
2. スイッチフォルダー
3. タイムライン
4. MP4 の書き出し

このあと、デフォーマ（ワープ・回転）とパラメータを足す。タイムラインはそのまま共有する。

## 1. 土台

- PSD のレイヤー ID（`lyid`）を読み書きする。ID のない PSD は保存のときに振る。
  サイドカーはこの ID でレイヤーを指す。
- サイドカーは `作品.psd` の隣の `作品.nanopic.json`。PSD を保存するとき一緒に書き、
  開くときにあれば一緒に読む。PSD として保存するまでは作らない。中身は版番号つきの JSON。

## 2. スイッチフォルダー

- フォルダーの種類に「スイッチ」を足す。子（レイヤーやフォルダー）のうち常に 1 つだけを表示する。
- PSD にはふつうのフォルダーとして、選んでいる子だけを表示・ほかを非表示で保存する。
  スイッチである印はサイドカーに持つ。ほかのアプリで開いても普通のフォルダーに見える。
- レイヤーパネルでは、スイッチの子の目のアイコンをラジオボタン風にする。子を選ぶと表示もその子に切り替わる。
- フォルダーの右クリックで「スイッチにする／普通に戻す」。

## 3. タイムライン

- キャンバスの下に、たためる帯として置く。閉じていれば今までどおりのペイントアプリ。
- キーフレームを打てるもの: スイッチの切り替え、レイヤーの表示／非表示。どちらもステップ（補間なし）。
- fps、長さ、ループ、再生。
- タイムラインもサイドカーに持つ。
- 行（トラック）を足す: タイムラインを出している間、レイヤーの右クリックで「タイムラインに足す」。
  1 コマ目に今の状態（表示／非表示、スイッチならどの子か）のキーを打つ。スイッチの子ならフォルダーの行にする。
  行があれば「タイムラインから外す」（キーも消える）。
- キーの操作: クリックで選び、Shift＋クリックで足す・外す。空いた所からドラッグで範囲選択。
  選んだキーのどれかをドラッグすると一緒に動く。⌘C・⌘V で今のコマを先頭に貼り付け、Delete で消す。
  目盛りのドラッグで再生位置を動かす。虫めがねのボタンでコマの幅を変える。
- パラメータのキー（リグ、5 章）には、次のキーまでの動き方（直線・ゆっくり始まる・ゆっくり止まる・両方・止める）を右クリックで選べる。
- オニオンスキン（タイムラインの上段で入り切り、前後に何コマ出すか）: 前のコマを赤、後ろのコマを青で薄く重ねる。
  今のコマと見た目が違う所だけを、暗いほど濃く出す（用紙や動かない所は重ならない）。遠いコマほど薄い。
  ループしていれば端で回り込む。再生中は出さない。作品には保存しない。

## 4. 書き出し

- MP4。

## 5. デフォーマとパラメータ

- **デフォーマ**はレイヤーかフォルダーに付ける。フォルダーに付けると中のレイヤー全部に効く。
  内側（レイヤー自身）から外側（親フォルダー）の順にかける。
  - 移動・回転: 中心を軸に回し、移動量だけずらす（形は角度と移動量）。
  - ワープ: 範囲を格子に分け、格子の点のずれで面を曲げる。点の間は 3 次の曲線（ベジェ）でつなぎ、
    マスの中は 4 辺から Coons パッチで埋める。点ごとに横・縦のハンドル（接線）があり、ふだんは隣の点から
    自動で決まる（なめらかにつながる）。ハンドルを動かすと、その分を「自動からのずれ」として形に記録する。
    キャンバスでは選んでいる点のハンドルを出し、ドラッグで向きと長さを変える（反対側も一緒に回る）。
    点かハンドルを右クリックすると、その点のハンドルを自動に戻す。
- **パラメータ**は名前つきのつまみ（最小・最大・既定値）。つまみのいくつかの値（キー）で、
  各デフォーマの形（基本の形からのずれ: 移動・回転は角度と移動量、ワープは格子の点のずれと移動量）を記録し、間は直線で補間する。
  ひとつのデフォーマを複数のパラメータで動かすときは、ずれを足し合わせる。
  既定値にキーがなければ、ずれ 0 のキーがそこにあるものとする（既定値はいつも基本ポーズ）。
- **タイムライン**でパラメータの値をキーフレームで動かす（直線で補間）。
- 描画: 動くレイヤーごとに、細かい格子（三角形の網）を基本の形からポーズの形へ写して画素を移す。
  移したあとは今の合成（合成モード・クリッピング・フォルダー）にそのまま通す。
- つまみが既定値から動いている間（ポーズ中）は変形した見た目を表示し、描けない。「基本ポーズに戻す」で戻す。
- デフォーマ、パラメータ、パラメータのタイムラインはサイドカーに持つ。

進め方:

1. コア: デフォーマ・パラメータ・ポーズの計算、サイドカー、エージェント向けのツール
2. 画面: タイムラインにパラメータのつまみとトラック、レイヤーの右クリックでデフォーマを付ける、ポーズの表示
3. キャンバス上でデフォーマのハンドル（回転の中心・角度、ワープの格子の点）を動かして形を記録する

## 6. リグモード（実験的な機能）

デフォーマとパラメータで絵を動かす画面。タイムライン（パラパラ）とは分けて、隠し機能にする。

- 設定の「実験的な機能」で「リグモード」を入れたときだけ、表示メニューに「リグモード（実験的）」（⌥⌘T）が出る。
  入っている間は、ウィンドウ上部に「描く｜リグ」の切り替えを出す。モードは作品ごとには覚えない。
- 描くモード: 今までの画面。変形は表示せず、描いた絵そのまま。タイムラインも出せる（7 章）。
- リグモード: 変形を表示し、描けない。
  - 左はブラシ設定の代わりに「リグ」パネル（パラメータのつまみと、編集中のレイヤー・親フォルダーのデフォーマ）。
    デフォーマをクリックすると、そのハンドルだけを出す（もう一度で全部）。
  - ツールは矩形選択・手のひら・ズームだけ。色とパレットは出さない。下にタイムラインを常に出し、パラメータの行も出す。
  - 矩形選択はデフォーマのハンドルを囲んで選ぶ（Shift で足す）。クリックで 1 つ、Shift＋クリックで足す・外す。
    選んだハンドルのどれかをドラッグすると全部が一緒に動く（中心の点とワープの点。腕は 1 つずつ）。Esc で選択を外す。
## 7. パラパラ（コマ送り）

スイッチフォルダーの子を 1 枚ずつのセルとして描く。描くモードで行う（変形を表示しないので描ける）。

- 描くモードでもタイムラインを出せる（ステータスバーの「タイムライン」、⌥⌘L）。パラメータの行はリグモードだけ。
- 「＋ セル」（⌥⌘N）: 今のコマに新しいセルを作ってキーを打ち、描く対象にする。名前は番号。
  編集中のレイヤーを含むスイッチフォルダーに足す。なければ編集中のレイヤーを最初のセルにしてスイッチフォルダーで包む。
- コマを移ると、描く対象がそのコマに出ているセルについてくる。「,」「.」で前後のコマへ。
- 空のコマ: スイッチの行のキーに「なし」。そのコマではフォルダーごと出さない（中のセルは 1 つ表示のまま）。
  フォルダーの目を閉じても「なし」のキーが打たれる。
- スイッチの行の右クリックで、そのコマに出すセル（または「なし」）を選べる。
- キーから次のキーまでを帯で出し、セルの名前を帯の中に書く。
