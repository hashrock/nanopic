# 書き出し（publish）

元の絵（PSD）は変えずに、決めた範囲を切り抜いて大きさを変え、決めた形式で書き出す。
設定は作品ごとに 1 組を、PSD の隣のサイドカー（`作品.nanopic.json` の `publish`）に持つ。

## 設定

- 範囲: キャンバスの座標の矩形（キャンバスの中に限る）。なければキャンバス全体
- 比率: 自由（既定）か、1:1・4:3・3:4・3:2・2:3・16:9・9:16 に固定
- 出力の大きさ: 幅を持ち、高さは範囲の比から決める（ゆがめない）。幅を入れていなければ等倍（範囲を変えても等倍のまま）
- 形式: PNG／JPEG（品質 1〜100）
- 透明な所: 透明のまま／白で埋める（JPEG はいつも白）
- 書き出し先: PSD と同じフォルダーの下なら PSD からの相対パス、そうでなければ絶対パス

設定の変更は取り消せ、保存が必要な変更として扱う。キャンバスの大きさを変えたら範囲もずらす（外れたらキャンバス全体）。

## 画面

- ファイル > 書き出し設定...: 開いている間だけ、キャンバスに書き出し枠（外を暗く、枠の上に出力の大きさ）と、
  右上に設定のパネルを出す。枠は角・辺のつまみで大きさを変え、内側のドラッグで動かす。
  比率を固定していればその比を保ち、自由のときも Shift を押しながらなら比を保つ。
  描くツールは使えない（手のひら・ズームは使える）。Return か OK で確定、Esc かキャンセルで開く前に戻す。
  - 範囲: X・Y・幅・高さ、比率、「キャンバス全体」「選択範囲から」
  - 出力: 幅・高さ（片方を入れるともう一方は比から）、「等倍」、倍率の表示
  - 形式、品質、透明な所、書き出し先（「変える...」）、「書き出す」
- 選択範囲 > 書き出し範囲にする: 選択範囲を囲む矩形を範囲にする（比を固定していれば、囲むようにその比で広げる）。
- ファイル > 書き出す（⌥⌘E）: 初回だけ書き出し先を聞き、2 回目からは同じ所に上書きする。ステータスバーに知らせを出す。
- 今見えている状態（表示中のレイヤー、今のコマ、リグのポーズ）を書き出す。

## 動画

動画の書き出し（MP4）も、書き出しの設定があればその範囲と大きさを使う（偶数に丸める）。

## エージェント向け

- `publish_settings`: 設定を見る・変える
- `publish`: 設定どおりに書き出す（destination で書き出し先を変えられる。拡張子から形式も合わせる）
