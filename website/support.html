Mac 版は macOS 14 以降。iPad 版は iPadOS 17 以降（描くには Apple Pencil を使います。指で描く設定もあります）。表示言語は日本語と英語です。

よくある質問

絵はどんな形で保存されますか？
PSD で保存します。保存した PSD は、ほかのアプリでもそのまま開けます。スイッチフォルダー・タイムライン・リグ・書き出しの設定のように PSD に入らない情報があるときだけ、PSD の隣に同じ名前の「作品.nanopic」（サイドカー）を作ります。
PSD を移動したら、タイムラインやリグが消えました。
その情報は隣の「作品.nanopic」に入っています。PSD を移動・名前変更するときは、「作品.nanopic」も同じ名前で一緒に動かしてください。「作品.nanopic」のほうを開こうとしたときは、PSD のほうを開いてください。
Mac App Store 版で、以前の版で作ったタイムラインやリグが読み込まれません。
以前の版は、サイドカーを「作品.nanopic.json」という名前で書いていました。Mac App Store 版は macOS のサンドボックスの中で動くので、開いた PSD の隣にあるファイルのうち、名前が同じで拡張子が「.nanopic」のものしか読み書きできません。Finder で「作品.nanopic.json」の名前を「作品.nanopic」に変えてから、PSD を開き直してください。このサイトからダウンロードした版で開いて保存し直しても、「作品.nanopic」ができます（古いファイルはそのまま残ります）。
Mac App Store 版で、「書き出す」（⌥⌘E）のたびに保存先を聞かれます。
サンドボックスの中では、あなたが保存パネルで選んだ場所にしか書けません。一度選んだ書き出し先は覚えて、次からはそこへ上書きします。ほかの Mac やダウンロード版で決めた書き出し先、形式を変えて拡張子が変わったとき、書き出したファイルを動かしたときは、もう一度選んでください。
iPad で、書類はどこにありますか？
ファイル App の「このiPad内 › Nanopic」です。iCloud Drive を使っていれば「iCloud Drive › Nanopic」にも置けます。アプリを離れると、この 2 つのフォルダーの書類は自動で保存します。
iPad で、ほかの場所の PSD を開くと印が出て、タイムラインなどが使えません。
iPad 版は、Nanopic のフォルダー（上の 2 つ）の中でだけサイドカーを読み書きします。外の場所の PSD は素の PSD として開き、サイドカーの情報は読まず、保存しても書きません。ツールバーの印を押して「Nanopic のフォルダーに複製して開く」を選ぶと、全部の機能が使えます。「作品.nanopic」があるときは、ファイル App で PSD と一緒に Nanopic のフォルダーへ移してください。
エージェント連携（MCP）が見当たりません。
エージェント連携は Mac 版だけの機能です。このサイトからダウンロードする版と Mac App Store 版の両方にあり、iPad 版にはありません。Mac では「設定」（⌘,）の「エージェント連携」で「MCP サーバーを有効にする」をオンにします。既定ではオフです。
Mac App Store 版のエージェント連携は、どのファイルを読み書きできますか？
あなたが Nanopic で開いた書類と、保存パネルで選んだ場所だけです。それ以外の場所は読み書きできません。
ブラシとパレットの iCloud 同期は、どこでオン・オフにしますか？
Mac は「設定」（⌘,）の「同期」、iPad はツールバーの書類メニュー（書類のアイコン）に、「ブラシとパレットを iCloud で同期」があります。既定ではオフです。Mac App Store 版と iPad 版でオンにすると、ブラシ・消しゴムのプリセットとパレットを、同じ Apple Account の Mac と iPad の間でそろえます。両方でオンにしてください。

Requirements

The Mac version requires macOS 14 or later. The iPad version requires iPadOS 17 or later (you draw with Apple Pencil; there is also an option to draw with a finger). The app is available in Japanese and English.

FAQ

What format is my artwork saved in?
PSD. Saved files open in other apps as they are. Only when a document has information that does not fit in a PSD (switch folders, the timeline, rigs, export settings), the app creates a sidecar file with the same name next to the PSD, such as “Artwork.nanopic”.
I moved a PSD and its timeline or rig disappeared.
That information is in the “Artwork.nanopic” file next to the PSD. When you move or rename a PSD, move or rename “Artwork.nanopic” along with it, keeping the same name. If you tried to open the “.nanopic” file itself, open the PSD instead.
The Mac App Store version does not load a timeline or rig made with an earlier version.
Earlier versions wrote the sidecar as “Artwork.nanopic.json”. The Mac App Store version runs inside the macOS sandbox, so next to the PSD you open it can only read and write a file with the same name and the “.nanopic” extension. In the Finder, rename “Artwork.nanopic.json” to “Artwork.nanopic”, then open the PSD again. Opening and saving the document with the version downloaded from this site also creates “Artwork.nanopic” (the old file is left as it is).
The Mac App Store version asks where to save every time I choose Export (⌥⌘E).
Inside the sandbox, the app can only write to a location you pick in the save panel. It remembers a location once you pick it and overwrites the file there from then on. You need to pick again for a location that was set on another Mac or in the downloaded version, when you change the format and the extension changes, or when you move the exported file.
Where are my documents on iPad?
In “On My iPad › Nanopic” in the Files app. If you use iCloud Drive, you can also keep them in “iCloud Drive › Nanopic”. Documents in these two folders are saved automatically when you leave the app.
On iPad, a PSD from another location shows a badge and the timeline is not available.
The iPad version reads and writes sidecar files only inside the Nanopic folders (the two above). A PSD elsewhere opens as a plain PSD: sidecar information is not read, and is not written when you save. Tap the badge in the toolbar and choose “Duplicate to the Nanopic Folder and Open” to use everything. If there is an “Artwork.nanopic” file, move it together with the PSD into the Nanopic folder in the Files app.
I can’t find agent integration (MCP).
Agent integration is only in the Mac versions: the one downloaded from this site and the Mac App Store version. The iPad version does not include it. On a Mac, open Settings (⌘,) and turn on “Enable MCP Server” under “Agents”. It is off by default.
Which files can agent integration read and write in the Mac App Store version?
Only the documents you opened in Nanopic and the locations you chose in a save panel. It cannot read or write anywhere else.
Where do I turn iCloud sync for brushes and the palette on or off?
On a Mac, open Settings (⌘,) and use “Sync”. On an iPad, open the document menu in the toolbar (the document icon). The switch is “Sync Brushes and Palette with iCloud”, and it is off by default. In the Mac App Store version and the iPad version, turning it on keeps brush and eraser presets and the palette the same on your Mac and iPad signed in to the same Apple Account. Turn this on on both.
